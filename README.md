## Описание проекта  
Приложение **«Task Manager»** предназначено для удобного управления списком дел.

### Основные возможности:
- Создание новых задач  
- Изменение существующих задач  
- Удаление задач  
- Сортировка по дате выполнения  
- Фильтрация по приоритету и статусу  
- Подсветка просроченных задач

---

## Требования
- Windows 10/11
- .NET 6 или .NET 8
- Visual Studio 2022

---

## Запуск проекта
1. Открыть файл `.sln`
2. Нажать `F5`
